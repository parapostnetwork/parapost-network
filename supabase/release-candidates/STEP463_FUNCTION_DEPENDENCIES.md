- Latest staging definitions take precedence over old drafts.
- Repeated function definitions require signature-level review.
- Existing production objects must not be overwritten blindly.
- Unique indexes and constraints must be reconciled together.
- Triggers require exact target-table and function checks.
- RLS and RPC permissions must preserve existing authorization.
- Notification routing must preserve owner and actor checks.
- Preserve seven-day sharing cooldown rules.
- Preserve blocking, moderation, comments and media access.
- Preserve production notification data and type constraints.
- Feature gates remain disabled by default.

## Security restrictions

- No function bodies copied into this inventory.
- No credentials or API keys copied.
- No staging SQL executed.
- No production SQL executed.
- No schema links changed.
